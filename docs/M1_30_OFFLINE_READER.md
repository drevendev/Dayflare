# Offline 30-title EN/RU atlas from retained normalized data

**UNPUBLISHED LOCAL READER — NOT PAGES / NOT LIVE.** Advances #12 and complements the pinned 30-title normalized candidate in [M1_30_RETAINED_CANDIDATE.md](M1_30_RETAINED_CANDIDATE.md).

The reader is a single standalone HTML file, generated without an API call or external assets from the repository-retained exact-byte candidate. It offers 30 selected titles across English/Russian Wikipedia, 35 observed UTC dates each (1,050 request values), a numeric final-week difference against the **median of four earlier seven-day totals**, search/edition filtering, keyboard-selectable ordering by absolute weekly difference or signed increase/decrease, expandable 35-day exact-value tables, two-series same-window comparisons (including a direct “Compare this article” shortcut on every card that selects its stable page ID and focuses the second selector), a downloadable exact 35-day paired CSV (UTC date, stable local IDs, request counts, dataset and method), a zero-based side-by-side five-week comparison chart with a shared scale and an exact accessible table, and dataset/method/ID-bound URL restoration. The CSV link appears only for two distinct valid histories and needs JavaScript. It is generated offline from the same pinned daily values and never requests a server. Every history and table exists in static HTML without JavaScript; interactive filtering and comparison need JavaScript.

From a clean checkout, using **Python 3.10+**:

```sh
python -m tools.m1_30_retained_candidate
python -m unittest tests.test_m1_30_retained_candidate tests.test_m1_30_reader -v
python -m tools.m1_30_reader --output /tmp/dayflare-30-offline.html
# Open the resulting new HTML locally. An existing destination is rejected.
```

**Measured-change ordering:** The default card order ranks absolute differences between the final seven-day total and the median of the four preceding complete weeks. Signed increase/decrease ordering moves the highest/lowest differences first; it does not classify topics as rising, returning or fading. With JavaScript disabled, all cards remain in the original absolute-difference order.
