03 / METHODS AND PROVENANCE

Follow the evidence, not a label.

Method v0-empirical-35d: sum each of five complete consecutive 7-day UTC windows. Compare 8–14 September with the median of the previous four weekly totals (11 August–7 September). Absolute change is last-week requests minus median; percentage is that difference divided by median. A zero median would make the percentage unavailable. These are descriptive comparisons, not validated “rising”, “returning” or “fading” classifications.

Source filter: all-access / user / daily. Here user is the Wikimedia API filter, not independently verified humans. All four HTTP 200 sources were retrieved on 25 October 2026, with 35 observed days apiece. The 140 exact values and metrics are versioned in this static JSON projection; source-body SHA-256 digests are shown with each table. The original raw HTTP response bodies remain in the time-limited source acquisition CI artifact and are not part of this checked-in projection. A hash proves byte consistency when the body is available, not independent source authenticity.
