# Dayflare

Dayflare is a research-first project for exploring changes in public attention through
reproducible, inspectable data.

The initial bounded source scope is English and Russian Wikipedia. Dayflare is intended
to help visitors discover topics that are rising, returning, or fading, inspect the
underlying evidence, compare language editions, and share a precise view.

The planned delivery path is static-first:

```text
scheduled CI -> collect -> validate -> calculate -> versioned static artifacts -> GitHub Pages
```

The project is currently in bootstrap/research phase. No public product or validated
coverage claim exists yet.

Product direction, measurement boundaries, and the initial research queue D01-D08 are
anchored in [issue #1](https://github.com/drevendev/Dayflare/issues/1).

Repository-canonical project controls and implementation will be added through normal
branch/pull-request flow after this initial base commit.
